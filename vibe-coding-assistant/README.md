# المساعد الذكي متعدد الوظائف (Vibe Coding Assistant)

تطبيق ويب يقدّم 10 خدمات نصية/برمجية عبر واجهة عربية واحدة، مبني بـ **FastAPI** (خلفية)
و **HTML + Tailwind CSS + JavaScript نقي** (واجهة). كل الردود الذكية حالياً هي **Mock**
(محاكاة مبنية على المدخلات) قابلة للاستبدال لاحقاً بـ Claude API حقيقي.

## التشغيل السريع

```bash
cd vibe-coding-assistant
pip install -r requirements.txt
python main.py
```

سيفتح المتصفح تلقائياً على `http://127.0.0.1:8000`. إذا لم يفتح تلقائياً، افتحه يدوياً.

## الميزات العشر

1. تحسين الأسلوب الكتابي — نص + جمهور مستهدف ← نص محسّن + جدول تعديلات.
2. تطوير الصوت الكتابي — رفع عينات نصوص ← دليل أسلوب (نقاط رئيسية).
3. العصف الذهني — موضوع + عدد أفكار ← قائمة أفكار مرتبة.
4. تبسيط المفاهيم — مصطلح + مستوى معرفي ← شرح باستعارة + أمثلة.
5. التحضير للاختبارات — مادة/منصب ← خطة دراسة + أسئلة تدريبية.
6. شرح مفاهيم البرمجة — مفهوم + لغة ← شرح + كود قابل للتجربة.
7. مراجعة الكود — لصق كود أو رفع ملف `.py` ← تقرير أخطاء + كود محسّن.
8. كتابة دراسة حالة — بيانات وأحداث ← تقرير منظم (مقدمة-تحديات-حلول-نتائج).
9. كتابة طلبات التمويل — فكرة + ميزانية ← مسودة طلب رسمية.
10. البرمجة التشاركية — نافذة دردشة تفاعلية مع ردود وكود مباشر.

المخرجات الطويلة أو الكود تُعرض في نافذة جانبية (Artifact Drawer) مع زر نسخ.

## هيكل المشروع

```
vibe-coding-assistant/
├── main.py                # نقطة التشغيل: python main.py
├── requirements.txt
├── app/
│   ├── config.py           # إعدادات + شرح كيفية تفعيل Claude API الحقيقي
│   ├── schemas.py          # نماذج pydantic لطلبات JSON
│   ├── mock_responses.py   # كل منطق "الذكاء" — دالة واحدة لكل ميزة
│   ├── routers.py          # 10 نقاط API تحت /api/*
│   ├── session_store.py    # جلسات مؤقتة في الذاكرة (لا قاعدة بيانات)
│   └── file_utils.py       # استخراج نص من PDF/DOCX/TXT/PY
└── static/
    ├── index.html          # الواجهة (تبويبات لكل ميزة)
    ├── css/style.css
    └── js/app.js           # منطق التبويبات + نافذة الـ Artifact + نداءات API
```

## صيغ الملفات المدعومة للرفع

`.pdf` `.docx` `.txt` `.py` — تُقرأ مباشرة في الذاكرة (لا يتم حفظها على القرص).

## التخزين

جلسات مؤقتة في الذاكرة فقط (`app/session_store.py`) — تُفقد عند إعادة تشغيل الخادم.
لا حاجة لأي قاعدة بيانات لتجربة المشروع.

## الاتصال بـ Claude API الحقيقي

كل الردود الذكية تأتي حالياً من `app/mock_responses.py`، ويشير كل استدعاء له في
`app/routers.py` بتعليق `# MOCK CALL`. للتفعيل الحقيقي:

1. `pip install anthropic`
2. عرّف `ANTHROPIC_API_KEY` كمتغير بيئة (راجع `app/config.py`).
3. استبدل استدعاء `mock_responses.xxx(...)` المطلوب في `app/routers.py` بنداء حقيقي، مثال:

   ```python
   import anthropic
   client = anthropic.Anthropic(api_key=config.ANTHROPIC_API_KEY)
   client.messages.create(model=config.CLAUDE_MODEL, max_tokens=1024, messages=[...])
   ```

لا حاجة لتغيير أي شيء في الواجهة الأمامية — شكل الاستجابة (JSON) يبقى كما هو.
